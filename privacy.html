Privacy policy

Last updated: 23 October 2026

The apps "IntoTheGreen" and "IntoTheBlue" are private tools used only by the owner of the IntoTheGreen and IntoTheBlue YouTube channels.

What data the apps access

With the owner's permission (Google sign-in), the apps read view counts, click-through rate and average view percentage of the owner's own YouTube videos, using the YouTube Data API and YouTube Analytics API with read-only access.

How the data is used

The numbers are saved on the owner's computer and in the owner's private planning notes. They are not sold, shared with third parties, or used for advertising.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the local token file also ends access.

The apps' use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. The apps use YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
